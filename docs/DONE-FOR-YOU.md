# Done-for-you install

**$499 once, one computer you own.** Booked through https://thefiredev.com/harness (TheFireDev, a MeshVault company).

## What happens

1. **20-minute call.** We check your machine (RAM, disk, OS, GPU), what you want the agent to do, and which accounts it should and should not touch.
2. **Install session, up to 90 minutes, screen-share.** We run the installer on your machine with you watching, pick the right model, install Hermes and OMP, and run `meshvault doctor` until it is green.
3. **One real workflow.** We build one thing you will use, for example: inbox triage with drafted replies, a weekly numbers summary, invoice follow-ups, or a daily standup from your notes. It uses the approval-gated skills, so nothing sends without your yes.
4. **Handover.** A one-page note with the commands you need, and the Pro skills pack installed.
5. **30 days of email support** for the install.

## Not included

* A second machine, a server rollout, or multiple users
* Custom software, integrations beyond the ones Hermes already supports, or hosting
* Cloud model or messaging service costs (you pay those providers yourself, if you use them)
* A guarantee that a small local model matches a cloud model on hard tasks. We will tell you which tasks fit and which do not before you commit to anything beyond the install.

## Refunds

If we cannot get a working install on your machine, you get the $499 back.
